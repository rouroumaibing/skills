# 场景②：多仓库查代码（不涉及特定客户版本）

## 约定
- 所有仓库在 `config.yaml` 的 `codehub`（本地路径）。用 `scripts/resolve_version.py --list` 可看组件与本地路径对应关系。
- 直接在 `codehub` 各本地路径下用 grep/ripgrep 搜索，不需要额外脚本。

## 流程
1. 从报错或日志中提取线索：类名、方法名、错误码、日志格式串、配置项名。
2. 先在 `codehub` 各路径下搜线索，按仓库归类命中结果。
3. 一个线索命中多个仓库时，先看调用方向（谁调用谁），再判断问题发生在哪个组件。
4. 追调用链时，列出每一跳的 `文件:行号`。
5. 搜不到时换线索重搜（日志文本常被拼接，搜固定片段而非完整句子）。

## 约束
- 这里看的是本地当前分支，**不代表客户版本**。涉及特定版本时必须转场景③。
- 结论中注明所读仓库的当前分支/commit（`git -C <path> rev-parse --short HEAD`）。
