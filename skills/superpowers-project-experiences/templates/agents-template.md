- {任务类型} → 读 {对应文档/目录}
- 生成/更新项目提示词 → 读 `templates/prompts-template.md` + 执行 Step 3
- ...

### 自动化经验推荐（新增）
**智能推荐系统自动执行**：基于当前任务关键词自动匹配 PROJECT_EXPERIENCES.md 中的经验切片：

```markdown
## 当前任务分析
- 任务描述: {从任务描述提取的关键词}
- 匹配标签: {自动提取的标签}
- 推荐经验: {匹配的经验切片列表（按匹配数排序）}

## 推荐结果
1. [{优先级}] {经验标题}（来源: {filename}.md）`{匹配标签}` - {匹配数}个标签
2. [{优先级}] {经验标题}（来源: {filename}.md）`{匹配标签}` - {匹配数}个标签
...
```

**推荐机制**：
1. 自动从任务描述提取标签关键词
2. 遍历 PROJECT_EXPERIENCES.md 中所有经验切片
3. 计算标签匹配数，按匹配数降序排列
4. 优先推荐匹配数 > 0 的经验切片
5. 同匹配数时：P0 > P1 > P2

> **使用方式**：直接加载推荐结果中的经验切片，无需人工匹配标签。

# 多模型配置支持（附录）

> 项目可能被不同 AI 模型操作。以下配置通过独立文件管理，按需加载。

项目可能被不同 AI 模型（Claude/Gemini/Codex 等）操作。AGENTS.md 作为通用入口，
各模型特定配置通过独立文件管理，按需加载：

### 配置文件约定

| 文件 | 作用 | 何时创建 |
|------|------|----------|
| `AGENTS.md` | 通用协作约定 + 文档索引 + 命令速查 | 总是存在（本 skill Step 2 生成） |
| `CLAUDE.md` | Claude 特定约束/偏好 | 项目用 Claude 操作时 |
| `GEMINI.md` | Gemini 特定约束/偏好 | 项目用 Gemini 操作时 |
| `CODEX.md` | Codex 特定约束/偏好 | 项目用 Codex 操作时 |

### 按模型加载协议

```
模型进入项目时:
  1. 先读 AGENTS.md（通用约定 + 文档索引）
  2. 检查是否存在 {MODEL}.md（如 CLAUDE.md）
  3. 存在 → 追加读取模型特定配置
  4. 不存在 → 跳过，仅遵循 AGENTS.md 通用约定
```

### 模型特定配置模板

```markdown
# {MODEL}.md — {模型名} 特定配置

> 本文件补充 AGENTS.md 中未覆盖的模型特定约束。
> 通用约定见 AGENTS.md，本文件仅写差异部分。

## 模型特定约束
- {约束1}: {说明}（如：Claude 优先用 Read 而非 cat）
- {约束2}: {说明}

## 模型特定加载
- {任务类型} → 额外读 {文件/目录}
```

### AGENTS.md 中的多模型索引

在文档索引表中添加模型配置文件条目：

```markdown
| 路径 | 摘要 | 何时该读 | 标签 |
|------|------|------|------|
| CLAUDE.md | Claude 特定约束 | 用 Claude 操作时 | 模型/Claude |
| GEMINI.md | Gemini 特定约束 | 用 Gemini 操作时 | 模型/Gemini |
```

> Step 2 生成 AGENTS.md 时，如检测到已有 CLAUDE.md/GEMINI.md 等文件，自动添加到文档索引表。
