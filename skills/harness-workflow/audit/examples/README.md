# audit/examples/ —— 演示脚本（非检查器）

本目录下的脚本是**度量范例 / 示例入口**，不是检查器：

- `test-upload` —— 文件上传成功率度量的示例探针（演示 `METRIC|` 通道 +
  `unit=` + `samples` 绑定约定，对应 schemas.md §1.1）。
- `bench-play` —— 起播时间 P95 度量的示例探针（同上演示度量通道约定）。

用途：供消费项目参照实现自己的度量探针——契约自动类判据（`criteria` 的
`type: auto`）的 `command` 应指向项目自建的探针入口，而不是直接依赖这里的
演示脚本。示例只演示"度量程序独占 `METRIC|` 发射、输出真实被测量、携带
`unit=`"的格式约定，不含任何项目业务逻辑，也不参与 `--self-test` 门禁。

对照：真正的检查器在 `audit/scripts/`（带 `--self-test` 反例夹具，退出码
`0` 通过 / `1` 违反 / `42` 未接线）。
