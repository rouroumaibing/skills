# 公司屏蔽名单机制 — jd-hunting

> 本文件是 `SKILL.md` 的公司过滤参考。

三层过滤架构，贯穿第三步检索到第六步评分：

## 第一层：静态硬黑名单（用户自定义，输入阶段）

- 前置输入的 `排除公司名单` 字段（可选）
- 第三步检索后、写入 `03-jobs-from-sites.md` 前过滤
- 直接剔除，不保留记录
- 写入 `outputs/00-index.md` 黑名单区

## 第二层：动态软标记（学历/外包，检索后）

**不剔除，标注 ⚠️ 风险标记**，第六步评分时按规则调整。

**模糊匹配规则**：招聘网站上的公司名称大多是工商注册全称或子公司名称（如"北京字节跳动科技有限公司"、"杭州阿里妈妈软件服务有限公司"）。采用**关键词包含匹配**——公司名字段包含内置名单关键词（或用户追加的公司名/关键词），即触发学历红线判定。用户追加的公司支持全称和关键词两种形式。

**名单内公司的双重标记**：名单内公司即使标注"✅ 年限突破"，仍保留"⚠️ 学历红线（大厂卡全日制）"标记作为风险提示——因为大厂 HR 筛选可能仍卡学历，年限突破不保证过筛。

### 学历软标记规则

岗位要求"全日制本科" + 用户学历为非全日制时：

| 条件 | 标记 |
| :--- | :--- |
| 用户工作年限 ≥ 岗位要求 +2 年 | ✅ 年限突破（学历可放宽） |
| 工作年限差距 ≤1 年 | ⚠️ 学历红线（年限可突破） |
| 工作年限差距 1-2 年 | ⚠️ 学历红线（年限边缘） |
| 工作年限差距 >2 年 | ❌ 学历不匹配（建议跳过） |

### 外包软标记规则

公司主体含"人力资源/劳务/外包/中智/外企德科/微创"等字样时：

| 条件 | 标记 |
| :--- | :--- |
| 所有情况 | ⚠️ 外包岗（请判断是否投递） |

不按用户学历区分，统一标注，由用户自行判断。

## 第三层：运行时动态硬黑名单（第六步查出红线公司）

- 第六步查到公司失信/社保 0/司法风险高（参考模板 C 红线判定）
- 自动加入本次运行黑名单
- 后续步骤不再推荐同公司其他岗位
- 写入 `outputs/00-index.md` 黑名单区

## 00-index.md 黑名单区动态追加

```markdown
## 黑名单
- {公司全称}（用户自定义黑名单）
- 猎聘（WebSearch 无结果）
- {公司全称}（运行时动态：失信被执行人）
```
