# 经验标签系统

> 每条经验可附标签（反引号包裹），用于任务驱动的经验推荐。

每条经验可附标签（反引号包裹），用于任务驱动的经验推荐：

| 标签类别 | 示例 | 用途 |
|----------|------|------|
| 领域 | `引擎` `UI` `网络` `存储` `构建` | 按功能域匹配 |
| 类型 | `重构` `新功能` `优化` `修复` `迁移` | 按任务类型匹配 |
| 风险 | `P0` `P1` `P2` | 按优先级匹配 |
| 技术 | `ESM` `CommonJS` `Electron` `WebSocket` | 按技术栈匹配 |

> **推荐机制**：当任务描述含某标签关键词时，优先推荐含该标签的经验切片。
> 标签在切片标题行末尾用反引号标注，如 `### 3. 卡组系统重构（来源: deck-restructure.md）`重构` `存储` `P1``

# 经验推荐系统

> 基于标签匹配的轻量推荐，不依赖复杂相似度计算或外部服务。

基于标签匹配的轻量推荐，不依赖复杂相似度计算或外部服务：

#### 推荐流程

```
1. 提取任务标签：从任务描述中提取关键词，匹配标签库
   - 任务"重构网络模块" → 标签: `重构` `网络`
   - 任务"添加新 UI 组件" → 标签: `新功能` `UI`

2. 标签匹配：遍历 PROJECT_EXPERIENCES.md 中所有经验切片
   - 计算匹配标签数（交集大小）
   - 按匹配数降序排列
   - 返回匹配数 > 0 的经验列表

3. 输出推荐：格式化推荐列表
   - 优先级：匹配数多 > 匹配数少
   - 同匹配数：P0 > P1 > P2
   - 展示：经验标题 + 匹配标签 + 来源文件
```

#### 推荐示例

```
任务: "重构卡组系统数据存储"
提取标签: `重构` `存储`
匹配结果:
  1. [P1] 卡组系统重构（来源: deck-restructure.md）`重构` `存储` `P1` — 匹配 2 标签
  2. [P2] 数据持久化迁移（来源: data-migration.md）`迁移` `存储` `P2` — 匹配 1 标签
推荐: 优先参考第 1 条经验
```

#### 在 AGENTS.md 中集成推荐

在按需加载协议中添加经验推荐入口：

```markdown
## 按需加载协议（重要）
- 当前任务标签: {从任务描述提取}
- 推荐经验: {标签匹配结果}
- → 先读推荐经验切片，再加载相关文档
```
