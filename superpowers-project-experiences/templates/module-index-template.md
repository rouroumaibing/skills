# 智能职责推断模板（附录）

> 基于目录/文件名关键词自动匹配职责描述模板，未匹配的标记「待人工审核」。

基于目录/文件名关键词自动匹配职责描述模板，未匹配的标记「待人工审核」：

| 关键词（目录/文件名含） | 自动填充职责 | 示例 |
|--------------------------|-------------|------|
| `engine` / `core` | 核心逻辑、物理计算、渲染管线 | `src/engine/` → 游戏引擎核心逻辑 |
| `ui` / `components` / `views` | 用户界面组件、交互逻辑、状态管理 | `src/ui/` → UI 组件层 |
| `net` / `network` / `api` | 网络通信、数据同步、API 调用 | `src/net/` → 网络通信模块 |
| `data` / `store` / `db` | 数据存储、配置管理、资源加载 | `src/data/` → 数据存储模块 |
| `effects` / `fx` / `particles` | 特效系统、粒子效果、动画 | `src/effects/` → 特效系统 |
| `screens` / `pages` / `routes` | 页面/屏幕级组件、路由入口 | `src/screens/` → 页面级组件 |
| `build` / `scripts` / `tools` | 构建脚本、工具链、自动化 | `build/` → 构建工具链 |
| `test` / `__tests__` / `spec` | 测试文件、测试工具、mock | `__tests__/` → 测试文件 |
| `config` / `conf` | 配置文件、环境变量、常量定义 | `config/` → 配置管理 |
| `utils` / `helpers` / `common` | 通用工具函数、辅助方法 | `src/utils/` → 通用工具函数 |
| `electron` / `shell` / `desktop` | 桌面应用外壳、原生集成、系统API | `electron/` → Electron桌面应用 |
| `api` / `service` / `server` | API服务、业务逻辑、数据处理 | `src/api/` → API服务层 |
| `worker` / `thread` / `task` | 后台任务、多线程、异步处理 | `src/worker/` → 后台任务处理 |
| `plugin` / `extension` | 插件系统、扩展机制、第三方集成 | `src/plugin/` → 插件系统 |
| `adapter` / `bridge` | 适配器、桥接层、兼容性处理 | `src/adapter/` → 适配器层 |
| `middleware` | 中间件、请求处理、管道过滤 | `src/middleware/` → 中间件层 |

> **推断规则**：精确匹配 > 模糊包含 > 默认「待人工审核」。一个目录可能匹配多个关键词，
> 取最具体的匹配。推断结果仅作为初始值，人工审核后可修正。
> **不依赖 AI 辅助**：纯关键词模板匹配，确定性强、零外部依赖。
